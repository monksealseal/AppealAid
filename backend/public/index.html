AppealAid API

Backend API for the AppealAid Insurance Appeal Automation Platform

Online

API Information

This is the backend API for AppealAid, a platform designed to streamline the insurance appeal process for healthcare providers and patients.

The frontend application communicates with this API to handle user authentication, appeal management, document processing, and more.

Available Endpoints

POST /api/users

Register a new user

POST /api/users/login

Authenticate a user

GET /api/users/profile

Get user profile (protected)

GET /api/appeals

Get all appeals (protected)

POST /api/appeals

Create a new appeal (protected)

GET /api/appeals/:id

Get appeal by ID (protected)

GET /api/peer-reviews

Get peer reviews (protected)

POST /api/peer-reviews

Create peer review (protected)

For a complete list of endpoints, refer to the API documentation.
